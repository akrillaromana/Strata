# Strata Custom — итерация 019

Персональный форк под конкретную установку владельца на `E:\ai\...` и `R:`. **Не рекомендован для использования другими пользователями без самостоятельной адаптации**. Бинарники, GGUF, ключи и GPU сборки не входят в архив.

В 019 нативный MTP runtime сохраняет **BF16 dense веса побайтово** (и Q8_0 как прежде) и направляет шесть dense GEMV + три shared expert проекции в GPU вычислительные пути соответствующих форматов. Предыдущие `--experts native` и Q2_0 runtime совместимы. Новая CPU-only проверка геометрии защищает от несовместимых длин матриц; Python и CPU регрессии проходят. **Работа на CUDA и конкретных больших GGUF не проверялась.** Shared-only MTP, полная Q6_K/Q8_0 модельная поддержка, vision и другие функции остаются открытыми (см. `docs/reports/iteration-019/TASKS.md`).
