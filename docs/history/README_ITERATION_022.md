# Strata Custom v0.1.39 — итерация 022

Исправлена проверка GGUF payload для всех нативных матриц Q6_K/Q8_0 (Unsloth и Huihui): обнаружение и загрузка используют один проверяемый C++ контракт геометрии строк, выравнивания, диапазонов и непересечения, **с проверкой всех шардов до первого GPU-выделения памяти**. Python-аудитор соответствует C++: не считает `[128,2]` корректной Q6_K-строкой только потому, что произведение измерений равно 256. Входные GGUF-модели и личные профили не менялись.

Тесты в среде ассистента: 125 Python unit-тестов, 55 JavaScript, 8 личных профилей, 4 автономных C++-теста GGUF (включая новый с 8 сценариями). Ни CUDA, ни реальная модель не исполнялись. **Не считать поддержку всей Q6_K/Huihui Q8_0 архитектуры завершённой.**
