# Strata Custom — итерация 017

Персональный форк, не предназначен для запуска «как есть» другими пользователями.

Новый отдельный офлайн-конвертер `tools/mtp_original_rt.py` разбирает оригинальные
MTP BF16/Q8_0 GGUF и по **явному** разрешению делает промежуточный Q2_0 runtime
для существующего drafter. Исходные Q8_0 dense-матрицы сохраняются побайтово.
Преобразование routed experts **с потерей точности**, поэтому **это НЕ полная
нативная поддержка BF16/Q8_0 MTP**. Не используется автоматически.

119 Python и 55 JavaScript тестов; никаких GPU/модельных испытаний.
Все персональные модели и запускные профили без изменений. Архитектурные задачи:
`docs/reports/iteration-017/TASKS.md` и `CONTINUE_PROMPT.md`.
