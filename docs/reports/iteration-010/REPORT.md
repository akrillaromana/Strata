# Итерация 010 — интеграция возможностей оригинальной Strata 0.1.41

**Основа:** личный форк на официальном теге v0.1.39, с изменениями 001–009. **Донор:** переданный пользователем `Strata-main(2).zip`, внутри проект `Strata-main/`, `project(strata VERSION 0.1.41 LANGUAGES CXX)`. Не подменять рабочую базу всем исходником донора.

**Последний подтверждённый опубликованный коммит ДО 010:** `e447d53` — итерация 009. Итерация 010 в этом ZIP ещё НЕ опубликована в GitHub. Целевая ветка `strata-v0.1.39-custom`.

## Перенесено и интегрировано

1. `serve/prometheus.py` — донорская совместимость с базовыми именами метрик vLLM, гистограммами TTFT, ITL, E2E, статистикой GPU и n-gram/MTP; добавлены защита лейблов от управляющих символов, от нечисловых/бесконечных величин, точный разбор `format=prometheus`.
2. `serve/server.py` — выбор JSON или Prometheus на существующем `GET /metrics` в зависимости от Accept/параметра; существующий JSON остается форматом по умолчанию. Гистограммы записываются в завершающей ветке генерации на уровне `Service` для каждого запроса.
3. `serve/test_prometheus.py` — оригинальные тесты HTTP-взаимодействий, параллельности и строковых метрик на mock-движке; без запуска GGUF/CUDA.
4. `tools/quantscope.py` — донорский инспектор реальных квантований GGUF и safetensors, локальных файлов/каталогов и HTTP Range, HF/ModelScope. Усилен ограничением размеров заголовка/диапазона HTTP, верхними границами метаданных и безопасной обработкой коротких/чрезмерных ответов. Не загружает целые GGUF-модели вместо их заголовков.
5. `tools/strata_inspect.py` и `data/gguf_fingerprints.json` — донорское сопоставление реального состава тензоров с известными upstream-файлами; статус совпадения отпечатка **не равен** успешному запуску в нашем форке, об этом прямо сообщается в CLI.
6. `setup.py --inspect SOURCE [VARIANT]` — подключён ранний вызов инспектора, завершающийся без обычной процедуры установки и без старта модели. Ничего не меняет в рабочих Q4/Huihui/IQ3_S путях.
7. `tools/donor_audit.py` — новый инструмент воспроизводимого сравнения двух ZIP-форков по SHA-256, без распаковки, с отказом на дублирующихся/опасных путях; результат сравнения 009→донор: `DONOR_FILE_MATRIX.tsv` (все 2505 уникальных путей).
8. `tools/test_quantscope_safety.py`, `tools/test_donor_audit.py`, `tools/test_strata_inspect.py` — модульные и защитные проверки.

## Что сознательно НЕ переносилось

- Самые новые C++/CUDA/VMM/DMA/speculative модули из 0.1.41 — не отдельные файлы: требуются согласованные изменения в `generate.cpp`, `expert_source.cpp`, заголовках, CMake и совместимость с нашим нативным Q6_K и GGUF Huihui. Нельзя заменить их целиком.
- `bench/results/*` (1415 новых файлов): исторические результаты и множество эталонных конфигов; не являются новыми runtime-функциями. Список учтён в TSV.
- Удалённые в доноре `(2)` экспериментальные SSD conversation cache и RAM-hot expert promotion из `(1)`. Не возвращать старый эксперимент просто из-за его наличия в предыдущем архиве; решение принимать по архитектуре и требованию пользователя.
- Не заявляется полноценная модельная совместимость Q6_K или Huihui Q8_0. Инспектор показывает только структуру GGUF, а не фактическую работоспособность GPU.

**Никаких команд сборки движка или запуска моделей на ПК пользователя.** Все PowerShell-команды переноса и GitHub публикуются напрямую в чате.
