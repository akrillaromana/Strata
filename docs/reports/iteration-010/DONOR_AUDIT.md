## Важно о втором донорском архиве

`Strata-main(2).zip` отличается от `Strata-main(1).zip`: 0 новых путей, **11 удалённых**, 14 изменённых. Среди 11 удалённых — `src/core/conversation_disk.cpp`, `include/strata/core/conversation_disk.hpp`, `src/program/local_memory_plan_test.cpp` и руководства по SSD/RAM-hot экспериментам. В текущем доноре соответствующие включения/параметры также удалены из `generate.cpp` и `expert_source.cpp`. Не называть вторую версию простым надмножеством первой.

## Приоритет для следующей итерации

1. Продолжить **нативные модельные форматы Q6_K и Huihui Q8_0**: не ограничиваться распознаванием заголовков. Сверять весь путь GGUF → pack → loader → dense/expert/PLE → CPU/CUDA dispatch → generation.
2. Изолировать донора для переноса `conversation_file` либо другой реально недостающей функциональности, сохранив пользовательские браузерные чаты.
3. Из донорского `src/program/generate.cpp` извлекать изменения небольшими проверяемыми блоками, не перезаписывая 0.1.39-форк целиком.
4. Оставшиеся важные интерфейсные задачи: настоящий token-level constrained JSON Schema; Anthropic structured output; контекстные параметры/профили/разделение настроек запуска.

До завершения этих задач **общая кодовая готовность не равна 100%**.
