# Strata Fork — итерация 034: диагностирование аварии движка IQ3_S

Дата: 11 октября 2026 года.
Основа: полный архив `Strata-Fork-IQ3S-iteration-033.zip`.

## Подтвержденное пользователем состояние

1. Сборка Strata через Ninja/MSVC/CUDA 13.3 уже прошла успешно, `strata.exe` существует в `E:\ai\Strata-Q4-Fork\engine`.
2. Пусковой сценарий находит два сегмента GGUF объёмом 51,05 и 26,82 ГиБ.
3. RAM-диск R: доступен, второй сегмент IQ3_S повторно используется, подготовка рабочей среды не сообщила об ошибке.
4. Python-сервер запускается, но его дочерний процесс `strata.exe` завершается до `READY`, из-за чего сервер выдаёт `RuntimeError: the engine exited before it was ready` и код 1.
5. Приведённый в чате вывод НЕ содержит `R:\strata-iq3s-runtime\strata-iq3_s.log`. Следовательно, причина завершения самого движка ещё не подтверждена. Нельзя утверждать, что исправлена проблема загрузки весов.

## Исправления исходного кода

- `serve/server.py`: сохранение последних 40 строк стандартного вывода дочернего движка в процессе и включение их в исключение при завершении до `READY`. Ранее строки, отличающиеся от `INFO` и `READY`, безвозвратно отбрасывались.
- `serve/server.py`: сохранение фактического кода завершения процесса в десятичной и шестнадцатеричной записи (в частности, для распознавания кодов завершения Windows NTSTATUS).
- `serve/test_server.py`: регрессионная проверка случая, когда движок сообщает об ошибке только через stdout и выходит с кодом 17.
- Все три одинаковые копии `START-IQ3S-RAM.ps1` (корень, `PERSONAL_START_E_ai_Strata-Q4-Fork`, `tools/windows/q4-local-profiles`): журнал stderr движка теперь создаётся вне очищаемой папки R: по пути `logs\iq3s\engine-<дата>.stderr.log`; в диагностике выводится место хранения; добавлена оценка доступной физической памяти до старта.
- Перед удалением старого `R:\strata-iq3s-runtime` сохраняется прежний `strata-iq3_s.log` на E: (`engine-previous-R-<дата>.stderr.log`), если файл существует. Это предотвращает потерю важной информации о предыдущем аварийном завершении.
- Добавлен `GET-IQ3S-DIAGNOSTICS.ps1`: режим только чтения, выводит свежие журналы движка и сервера, сведения о физической памяти, загрузке видеокарт, последних событиях Windows Application Error по `strata.exe`; сохраняет диагностику в `logs\iq3s\DIAGNOSTICS_LAST.txt`.

## Запуск и получение диагностики (после ручной распаковки пользователем)

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
Set-Location 'E:\ai\Strata-Q4-Fork'
& '.\START-IQ3S-RAM.ps1'
& '.\GET-IQ3S-DIAGNOSTICS.ps1'
```

Файл `E:\ai\Strata-Q4-Fork\logs\iq3s\DIAGNOSTICS_LAST.txt` содержит диагностику для следующей итерации. Если исполняемый файл Strata действительно отсутствует, использовать уже существующий `BUILD_AND_START_IQ3S.ps1`, а не производить полную сборку при каждом диагностическом запуске.
