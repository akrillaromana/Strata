# Оставшиеся задачи — итерация 045

1. В Windows выполнить `tools\TEST-MODEL-LAUNCHERS.ps1`, затем `python tools\ensure_gguf_py.py` и полный запуск `START-Q8-RAM.ps1 -PreparePack -AllowBf16Conversion`; подтвердить применение версий 045.
2. Подтвердить путь библиотечного модуля `gguf-py`: предпочтительно из CMake `_deps`, иначе из закреплённой ревизии GitHub, без обновления глобального Python.
3. Дождаться создания собственного Q8-пакета и проверить `index.txt`, `dense.bin`, `native_experts.txt`, `tokenizer/vocab.json`, `Q8-PACK-SOURCE.json`.
4. Оценить точность и производительность конверсий отдельных плотных проекций BF16; исходную PLE Q8_0 и GGUF менять нельзя.
5. Проверить, что после подготовки Q8 хватает 64 ГиБ RAM-диска для PLE, пакета и резервов; при недостатке места НЕ удалять неизвестные файлы и не переиспользовать пакеты других моделей.
6. Испытать Q8 до `READY`, `/v1/models` и текстовой генерации, с журналами движка и сервера.
7. Отдельно проверить Q4/Huihui и восстановление устройства AIM R: на Windows, без опасных автоматических операций.
8. Завершить калибровку всех поддерживаемых профилей по реальным измерениям, не ухудшая качества ради неподтверждённого ускорения.
9. Для новой итерации сохранять полный ZIP без общей верхней папки, отчёт и корневой промпт, давать только команды PowerShell для запуска/сборки/диагностики.
