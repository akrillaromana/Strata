# TASKS после итерации 053

1. На Windows запустить любую модель и открыть Web UI после обновления.
2. Проверить `Default from model config`: значения должны совпадать со стартовым профилем/применённым autotune.
3. Поставить, например, PCIe 0.00 / MTP 0.90, отправить запрос; затем PCIe 0.20 / MTP 1.00 без рестарта и сравнить строку под ответом.
4. Убедиться, что пользовательские JSON после этих действий не меняются.
5. Продолжить аппаратный CPU↔CUDA parity test итерации 052 отдельно; Web runtime tuning не подменяет parity mode.
