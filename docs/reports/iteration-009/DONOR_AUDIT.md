# Адресная сверка с `Strata-main(1).zip`: итерация 009

Исходники сравнивались **после** нашей итерации 008 с предоставленным донором `Strata-main(1).zip`. Донор более новый и существенно отличается (сотни изменённых исходников); его нельзя накладывать полностью на строго закреплённую базу `v0.1.39`.

| Компонент | Наш 008 | Донор | Действие в 009 |
|---|---|---|---|
| `tools/iq_pack.py` PLE-ключи | нативно Q2_0/Q8_0 | дополнительно IQ3_XXS/IQ4_XS | **Интегрировано**, так как C++ NativeDense уже знает эти типы |
| `tools/strata_pack.py` пакеты | мог перезаписать существующий pack | маркеры + `--force` | **Интегрировано и адаптировано**, защита default и tests |
| `src/kernels/ngram.cpp` | Q8_0 PLE, потенциальное переполнение | проверки размеров до pointer | **Интегрирован безопасный арифметический контракт**, отдельный CPU header/test |
| `tools/strata_inspect.py` / `quantscope.py` | отсутствовали | fingerprint известных GSQ пакетов, ModelScope/HF | **Создан адаптированный локальный `tools/model_compat.py`** без ненадёжного обещания исполнения GGUF по fingerprint; онлайн-инспектор остаётся задачей |
| `src/core/native_dense.cpp` | содержит частное исправление Huihui | другие allocator/packed Q8 возможности | **Не перезаписывался**: возможна регрессия Huihui multishard и отсутствующие зависимости; требуется точечный аудит |
| `src/kernels/cuda/iq_kernels.cu` | Q6_K opt-in из 006 | расширенные CUDA kernels | **Не заменялся** без полного анализа потребителей и версий ABI |
| `tools/strata_pack.py` forced rebuild | маркеры и невалидирующий manifest отсутствовали | логика удаления маркеров | перенесено, но не считается транзакционной атомарной публикацией |

## Новые возможности донора, которые НЕ считаются перенесёнными

- Специальные memory/VMM/allocator, DMA, resident planning, эксперты и fused CUDA, adaptive speculation, MTP, нетривиальные локальные контейнеры диалогов.
- Prometheus, дополнительные API/HTTP security, reasoning recovery, chunked bodies, cancel/race guards.
- Дополнительные `strata_inspect`, `quantscope`, research/benchmark/setup инструменты, advanced quantization/parity tests.
- Обновлённый `setup.py` донора со всеми версиями моделей и dependencies. Переносить его целиком нельзя: может затронуть рабочие профили и release-матрицу 0.1.39.

## Граница доказательств

Результаты `tools/model_compat.py` получены по заголовкам, типам тензоров и опубликованным в наших исходниках возможностям native MMVQ/PLE. Они **не являются** тестом полной CUDA-поддержки, достаточной памяти, правильности output или загрузки конкретного Huihui Q8 GGUF. Наличие Q6_K CUDA ветвей само по себе не подтверждает полный Q6_K end-to-end.
