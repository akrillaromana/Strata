## Код, написанный вручную

1. Новый `serve/web/presets.js`: формат `strata-sampling-presets` версии 1; строгий разрешённый перечень 14 полей, диапазоны чисел, целочисленные значения, ограничение имён и количества, защита от неизвестных полей и дублирования, создание/замена/удаление без мутации исходного документа.
2. `serve/web/index.html`: панель профилей, кнопки сохранения, загрузки, удаления, экспорта, импорта. Никаких внешних библиотек или сетевых вызовов для хранения профилей.
3. `serve/web/app.js`: раздельные черновые и активные настройки; выбор профиля **не** изменяет активную генерацию; кнопка Apply остаётся точкой применения; предустановки хранятся локально; ошибки сохранения и импорта показываются пользователю; испорченные данные не переписываются молча.
4. `serve/web/components.css`: адаптивная раскладка панели.
5. `serve/web/test_presets.js`: 16 проверок логики JSON, пределов, имён, отсутствия посторонних полей.
6. `serve/test_server.py`: новая HTTP-проверка наличия интерфейса и корректной отдачи нового JS через `/web/presets.js`; тест отдачи статических файлов расширен.
7. `README_ITERATION_003.md`, `README_RU_CUSTOM.md`, `CONTINUE_PROMPT.md`, `docs/reports/iteration-003/TASKS.md` — документация и продолжение.

## Проверки и честные ограничения

- `node --check serve/web/app.js serve/web/presets.js`: синтаксис обоих файлов принят (команды выполнялись отдельно).
- `node --test serve/web/test_presets.js`: 16/16 пройдено.
- `python -m unittest -v serve.test_server.SamplingKeys serve.test_server.SharedSettings serve.test_server.WebApp`: 21/21 тест пройден до добавления нового HTTP-теста.
- `python -m unittest -q serve.test_server.WebApp`: 10/10 пройдено после добавления нового HTTP-теста. Итого актуальная выборка из трёх групп содержит 22 теста (3 + 9 + 10).
- Chromium, тестовая страница со встроенными сценариями, **без настоящего API Strata**: сохранение, выбор, загрузка, применение, экспорт, удаление, импорт, отказ от вредоносных посторонних полей — пройдено, JS-ошибок нет.
- Chromium, адаптивность при ширине 375px: горизонтального переполнения нет.
- Полный набор Python-тестов, реальная Windows/CUDA-сборка и тест с моделью на компьютере пользователя: **не выполнялись**.
- Открыть локальный сервер в контейнерном Chromium напрямую не удалось из-за ограничения браузерной среды. Поэтому использована изолированная HTML-страница с реальными сценариями JS и моделью localStorage, а не выданы ложные утверждения о полноценной проверке HTTP.

## Безопасность и совместимость

- Не затронуты `src/core/native_dense.cpp`, `src/program/generate.cpp`, сборка и параметры Q4/Huihui/IQ3_S.
- Сохранились `host=0.0.0.0`, порт `8080`, MTP, RAM-диск R: и разделённые пакеты Huihui.
- Никаких секретов, ключей, GGUF или пакетов в новом формате JSON нет; неизвестные поля не принимаются, экспортируется только разрешённая схема.
- Выбор или импорт профиля сам по себе не меняет запрос. Для изменения генерации нужен Apply; для применения к чужим API-клиентам требуется отдельная опция Use for other apps too.
- Настройки не синхронизируются между браузерами, поэтому формат экспорт/импорт нужен именно для переноса.
