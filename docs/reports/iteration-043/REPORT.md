# Отчёт итерации 043 — RAM-диск AIM и собственный пакет Q8_0

## Основание: реальный журнал PowerShell 7.6.6

- `tools/TEST-MODEL-LAUNCHERS.ps1` — все 8 первоначальных файлов прошли проверку синтаксиса на Windows.
- `START-Q8-RAM.ps1` останавливался до проверки модели, так как отсутствовал нативный `pack/tokenizer` Q8_0.
- `START-Q4-RAM.ps1` определял отсутствие `R:\`, вызывал `aim_ll -a -t file -o awe -s 64G -m R:` и получал код 3: «Невозможно создать файл, так как он уже существует». Не доказано, зарегистрирован ли прежний RAM-диск, осталось ли его устройство без буквы или повреждён драйвер; это определит отдельная диагностика.
- Успешная загрузка и генерация IQ3_S и сборка C++/CUDA подтверждены предыдущими журналами и в этой итерации не изменялись.

## Ручные изменения исходников

1. В общий `STRATA-MODEL-LAUNCH-COMMON.ps1` добавлена `Ensure-StrataModelRamDisk`: проверяет существующий R:, NTFS/метку `STRATA_PLE`/минимальный размер, обнаруживает единственный подходящий том без буквы и назначает ему R: через `Get-Partition` / `Add-PartitionAccessPath`. Чужие тома, тома с другими буквами и неоднозначные варианты не переназначаются. Если подходящего тома нет, сохраняет список AIM до и после попытки создания. При коде ошибки останавливается, не удаляя устройства, с указанием `logs/ram-disk/RAM_DISK_LAST.txt`.
2. Добавлен отдельный безопасный `CHECK-STRATA-RAM-DISK.ps1`, собирающий список устройств AIM, Windows Storage, разделов, томов и точек монтирования. Ничего не монтирует, не форматирует, не удаляет.
3. `START-Q4-RAM.ps1` и `START-HUIHUI-Q4-RAM.ps1` теперь используют общий помощник и не завершают действующую модель через `Stop-Process -Force`. Порт и живые процессы Strata проверяются перед работой с RAM. Проверка метки `STRATA_PLE` обязательна до очистки временных файлов.
4. `START-Q8-RAM.ps1`: сначала проверяет наличие шести GGUF и настоящий `Q8_0` n-gram/PLE, затем — нативный пакет. При отсутствии пакета предлагает его создание по явно переданным `-PreparePack -AllowBf16Conversion`. Для отдельного пакета вызывает существующий `tools/iq_pack.py --compat-bf16` в каталог `*.building`, проверяет обязательные файлы и сохраняет `Q8-PACK-SOURCE.json`, включая SHA-256 первого GGUF, размеры всех шести шардов и квантование PLE. Сборка публикуется после завершения; неполный каталог не перезаписывается. Для повторного запуска сверяет происхождение собранного пакета с моделью.
5. Аналогичные скрипты синхронизированы в `tools/windows/q4-local-profiles`; корневой Q8 обрабатывает новые параметры и передаёт их в личный запускатель.
6. В `tools/TEST-MODEL-LAUNCHERS.ps1` включён новый диагностический файл (теперь 9 файлов).

## Ограничения по качеству и безопасности

- При совместимой конвертации небольшие плотные проекции могут округляться до BF16; это **не** побитово идентичные первоначальные веса. Операция включается только по явному разрешению пользователя. Крупная Q8_0 PLE и нативные эксперты сохраняются в исходном GGUF-формате.
- Не используются пакеты IQ3_S или Q4 вместо Q8. Не подменяется таблица PLE на IQ4_NL. GGUF на E: не изменяются.
- Ни один код не выполняет `aim_ll -d`, `aim_ll -D`, `format`, принудительный `Stop-Process` или удаление пользовательских данных.
- Функция `Ensure-StrataModelRamDisk` может восстановить только однозначный том, который Windows Storage видит по метке/размеру/ФС. Если устройство AIM осталось зарегистрировано, но Windows не обнаруживает том, автоматически исправить такое состояние **не подтверждено**. Отчёт потребуется для следующей целевой итерации.
- C++/CUDA, IQ3_S и значения параметров качества не менялись. Сборка движка не требуется.
