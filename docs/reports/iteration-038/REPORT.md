# Strata Fork — технический отчёт итерации 038

Дата: 11 октября 2026 года.

**Основной проект:** полный `Strata-Fork-IQ3S-iteration-037.zip` (форк `akrillaromana/Strata`, источник `strata-v0.1.39-custom`). **Донор:** предоставленный `Strata-main(3).zip`, где `CMakeLists.txt` объявляет `project(strata VERSION 0.1.43 ...)`. Исходный проект не заменён донором. Цель — адресный перенос оптимизаций при сохранении личного GSQ-RCO IQ3_S и восстановление живого вывода запросов в консоли.

## Факты сравнительного аудита

- Общих файлов: 858 (из них 335 различаются); только у донора: 2118; только в нашем архиве: 297. Это сравнение имён и контрольных сумм, а не полноценный функциональный аудит каждого метода; **не выдавать его за полный перенос**.
- Наиболее важные блоки изменений донора — `src/program/generate.cpp`, `src/prefill/`, `src/core/verify.cpp`, `src/core/expert_source.cpp`, `src/kernels/cuda/*`, `src/kernels/cpu/iq_avx2.cpp`, `serve/server.py`.
- Документация донора описывает для RTX 3060 **IQ3_XXS** +15,6% decode от `STRATA_ROUTE_TAIL_SKIP` (пропуск слабых некэшированных экспертов), до +30% в сочетании с новым выбором `pcie_frac` (но `--pcie-frac` у нашего GSQ-RCO уже вручную закреплён на 0.26), 19–28% экономии времени префилла коротких запросов при использовании CPU. Это **не доказательство +15%** у нашей IQ3_S. Пропуск малозначимых экспертов меняет результаты модели, поэтому его нельзя включать без проверки качества и сравнения с действующими GSQ-RCO решениями.

## Внесённые вручную изменения исходников

1. `src/kernels/cpu/iq_avx2.cpp`: частично перенесён IQ3_S AVX2-разбор из донора — девятый бит индекса разносится компилируемой таблицей, сигны считываются в один 256-битный вектор, а масштабы представлены заранее подготовленной `constexpr`-таблицей. Арифметика, порядок накопления суммы, кодовая таблица IQ3_S и режим `STRATA_IQ256_GATHER` сохранены. **Это не копирование всего donor-файла**: другие форматы квантования и алгоритмы форка не заменены.
2. `src/kernels/cuda/fused_gdn.cu`: независимые `red_kv` и `red_o` убирают одну межблочную синхронизацию, не меняя математический порядок двух сокращений.
3. `src/kernels/cuda/kv_stream.cu`: `atomicAdd(&s_lookups, lookups)` выполняется только при положительном значении `lookups`; нулевое прибавление не влияет на результат и исключено.
4. `START-IQ3S-RAM.ps1` и `PERSONAL_START_E_ai_Strata-Q4-Fork/START-IQ3S-RAM.ps1`: по умолчанию сервер работает в текущем терминале; включены `STRATA_REQUEST_LINES=1` и небуферизованный вывод Python. Через существующий `serve/server.py` ежесекундно выводятся чтение запроса, генерация токенов, итоговые скорости и сведения о кэше. Восстановлен вывод, пропавший из-за `Start-Process -RedirectStandardOutput` и немедленного возврата в PowerShell после READY. Прежнее фоновое поведение оставлено под ключом `-Detached`; `-Foreground` сохранён для совместимости. При возможности ведётся журнал `logs/iq3s/console-*.log`; если вложенная расшифровка не поддерживается, это не блокирует запуск. Параметр `-PcieFrac` позволяет вручную измерять 0.20 против неизменного значения 0.26 без пересборки и скрытой смены профиля.
5. `PERSONAL_START_E_ai_Strata-Q4-Fork/START-HERE IQ3_S.bat`: сообщение «сервер запущен» после выхода из долговременного процесса заменено на корректное «сервер остановлен».
6. `GET-IQ3S-DIAGNOSTICS.ps1`: добавлен вывод последней живой консоли.
7. `BENCHMARK-IQ3S.ps1`: три детерминированных коротких запроса (по умолчанию), измерение серверного поля `timings`, запись `logs/iq3s/BENCHMARK_IQ3S_LAST.txt` без модификации модели или секретов.
8. `BUILD_AND_START_IQ3S.ps1`: перед заменой существующего `engine/strata.exe` создаётся отдельная резервная копия в `engine/backups/strata-before-038-<дата>.exe`. При неудачной CUDA-сборке старый исполняемый файл не затрагивается; при успешной сборке пользователь имеет путь восстановления. Перед сборкой требуется остановить ранее запущенный процесс Strata, чтобы Windows разрешила обновить `strata.exe`.

## Проверки

- Исходный и обновлённый `iq_avx2.cpp` независимо скомпилированы Clang с `-mavx2 -mfma -mf16c` в Linux.
- Тест побитового сравнения 4 800 выходных значений IQ3_S AVX2 прошёл **4800/4800**, включая 1/2/3/4 токена и 1/2/4 блоков. Дополнительный запуск с `STRATA_IQ256_GATHER=1`: **4800/4800**.
- Вторая копия сценария запуска сверена с корневой; параметры GSQ-RCO, PLE, RAM, RTX 3060, `--kv int8`, `--max-context 262144`, MTP, профиль экспертов и пути пользователя не изменены.
- **Нет подтверждения компиляции CUDA под Windows и тестов производительности на RTX 3060 в этой среде.** Не заявлять о 15% прироста по результатам статических проверок и теста AVX2.
- Изолированная компиляция всего донора вместе с нашим форком **не проводилась** и не может считаться завершённой.

## Выполнение на компьютере пользователя

Пользователь самостоятельно распаковывает архив в `E:\ai\Strata-Q4-Fork` (без верхней папки). Затем в одном PowerShell 7:

Сначала остановить ранее запущенный сервер (`Ctrl+C` в его окне), если он работает: замена выполняемого файла при работающем процессе Windows может завершиться отказом в доступе.

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
Set-Location 'E:\ai\Strata-Q4-Fork'
& '.\BUILD_AND_START_IQ3S.ps1' -BuildOnly
& '.\START-IQ3S-RAM.ps1'
```

Последняя команда должна оставить окно открытым и выдавать живой вывод обработки запросов. В другом PowerShell можно проверить генерацию и скорости:

```powershell
Set-Location 'E:\ai\Strata-Q4-Fork'
& '.\VERIFY-IQ3S-API.ps1'
& '.\BENCHMARK-IQ3S.ps1'
```

Не закрывать окно сервера до теста. `Ctrl+C` завершает сервер. Повторное копирование 26,82-ГиБ PLE при валидной копии на RAM-диске не требуется. Чтобы сохранить прежний фоновый режим, `& '.\START-IQ3S-RAM.ps1' -Detached`.
