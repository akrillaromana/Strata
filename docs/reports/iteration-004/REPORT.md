## Ограничения и семантика

- Стоп ищется только в **видимой текстовой части ответа**; внутренние рассуждения и аргументы вызова инструмента не считаются текстом ответа. Это намеренное разграничение.
- Стоп-строки — текст, а не идентификаторы токенов. Действует при разбивке по токенам, без их повторного вывода.
- В UI вводится одна стоп-строка на строку. Стоп, содержащий буквальный перевод строки, доступен через API, но не через текущее поле UI.
- Для каждой операции допускается до 16 непустых уникальных строк, не более 256 символов в одной и 2048 в сумме; в браузере предустановки имеют те же пределы. Некорректные API-запросы возвращают 400.
- Возвращаемые метрики `completion_tokens` учитывают обработанные токены, включая токены завершения; видимый ответ их не содержит.
- Остановка в ходе структурированного JSON может привести к проверяемой ошибке несоответствия JSON-схеме. Стоп внутри рассуждений не применяется.
