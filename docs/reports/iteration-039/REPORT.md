# Strata Fork — отчёт итерации 039

Дата: 12 октября 2026 года. Предыдущая итерация: 038. Статус: **частично завершено**, доступна работающая модель по пользовательскому журналу, нововведённая автонастройка ещё не испытана на компьютере пользователя.

## Основание итерации

Пользователь подтвердил работу двигателя на RTX 3060 и реальную генерацию. Внешняя проверка `VERIFY-IQ3S-API.ps1` дала успешные `/health`, `/v1/models`, `/v1/chat/completions` и текст «ГОТОВО» (21 входной и 4 выходных токена). Команда `BENCHMARK-IQ3S.ps1` остановилась на ошибке синтаксического разбора PowerShell 7.6.6: в интерполируемой строке `$Model:` двоеточие было ошибочно воспринято как часть обращения к переменной.

В архиве Strata-main(3).zip, где проект имеет версию 0.1.43, обнаружена штатная калибровка `tools/calibrate.py`, интегрированная в `setup.py --calibrate`. Тот же механизм уже присутствовал и в нашем форке 0.1.39, но штатный режим `setup.py` рассчитан на иную схему установки и в процессе калибровки возвращает часть аргументов движка к общим значениям по умолчанию. Для GSQ-RCO IQ3_S это риск потери вручную выбранных `--pcie-frac 0.26` и `--spec-min-p 0.75`, изменения конфигурации или повторной загрузки модели.

## Адресные изменения

1. `BENCHMARK-IQ3S.ps1`: исправлено **три** синтаксически неверных обращения `$Model:` / `$i:` → `${Model}:` / `${i}:`. Расчёт исходных серверных `timings` и отсутствие скрытого изменения модели сохранены.
2. `TUNE-IQ3S.ps1`: новый самостоятельный подбор скорости на уже работающей модели через реализованный в Strata параметр `strata_tune` обычного запроса. Измеряет `pcie_frac` и `spec_min_p` при 3 раундах с переменным направлением обхода; использует серверный `timings.predicted_per_second` и медиану. Делает дополнительное чередующееся сравнение победителя с текущим профилем. Принимает изменение только если преимущество не менее 3%, иначе рекомендует сохранить исходные значения. Повторную компиляцию, загрузку GGUF, очистку RAM-диска или остановку сервера не выполняет. Изменение численных параметров может немного влиять на вычислительный результат, поэтому запись новых параметров только по явному `-Apply`.
3. Новые настройки пишутся в отдельный файл `IQ3S_AUTOTUNE.json`. В нём находятся имя модели, SHA-256 исполняемого файла и только две подобранные величины. Протокол всех измерений пишется в `logs/iq3s/AUTOTUNE_IQ3S_LAST.json` без токенов доступа и полных ответов модели. Установка новых параметров происходит **лишь при последующем запуске**.
4. `START-IQ3S-RAM.ps1`, `PERSONAL_START_E_ai_Strata-Q4-Fork/START-IQ3S-RAM.ps1`: при создании конфигурации проверяют привязку сохранённого профиля к сборке `strata.exe`; при несовпадении используют прежние `0.26/0.75`. Явно указанный `-PcieFrac` имеет приоритет. Ключ `-IgnoreAutotune` позволяет всегда запустить прежний базовый профиль без удаления файла калибровки. Размещение GSQ-RCO, PLE, MTP, KV, размер контекста, создание и повторное использование RAM-диска оставлены прежними.

## Исследование основной Strata 0.1.43

`tools/calibrate.py` новой версии дополнительно перебирает долю PCIe до 1.0, варианты уменьшения CPU-потоков, включая 1/4 первоначального количества, и параметры адаптации VRAM-кэша (`--adapt-every`, `--adapt-swaps`, `--adapt-decay`). Большая часть этого требует **перезапуска движка для каждого кандидата** и не может безопасно измеряться одновременно с сервером, занимающим почти всю видеопамять. Поэтому безопасный живой подбор в 039 ограничен двумя параметрами с поддерживаемым протоколом настройки отдельных запросов. Полная версия с CPU-потоками и адаптивным кэшем остаётся отдельной задачей для согласованной процедуры с остановкой текущего сервера.

## Команды пользователя после самостоятельной распаковки

При уже запущенном сервере в **первом** окне второе окно PowerShell 7:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
Set-Location 'E:\ai\Strata-Q4-Fork'
& '.\BENCHMARK-IQ3S.ps1'
& '.\TUNE-IQ3S.ps1' -Apply
```

Затем закрыть сервер в первом окне через Ctrl+C и запустить там `& '.\START-IQ3S-RAM.ps1'`, чтобы применить выбранные параметры (если подтверждён прирост). Если важнее точно сохранить прежнее вычислительное поведение, выполнить запуск `& '.\START-IQ3S-RAM.ps1' -IgnoreAutotune`.

Прислать `logs/iq3s/BENCHMARK_IQ3S_LAST.txt`, `logs/iq3s/AUTOTUNE_IQ3S_LAST.json` и фактический вывод новых запусков.
