# Отчёт об итерации 036 — восстановление отсутствующей cuBLAS при запуске IQ3_S

Дата: 11 октября 2026 года. Основной проект: `Strata-Fork-IQ3S-iteration-035.zip`.

## Установленный дефект по пользовательским журналам

Диагностика `dumpbin.exe /dependents` однозначно определила неразрешённый статический импорт `cublas64_13.dll` у `E:\ai\Strata-Q4-Fork\engine\strata.exe`. Windows возвращает `0xC0000135 (STATUS_DLL_NOT_FOUND)`. Поэтому Strata не успевает войти в `main()`, сервер Python получает завершение движка до `READY`, а лог движка пуст. Результат GET `/v1/models` — соединение отклонено. Компиляция CUDA 13.3.33 под RTX 3060 `sm_86` ранее успешно завершилась; **повторная сборка для этой итерации не требуется**.

Журнал на R: со старой сессией `engine 0.1.39` не относится к текущему отказу загрузчика. Его нельзя выдавать за успех новой итерации.

## Выполненные изменения

1. В `STRATA-WINDOWS-RUNTIME.ps1` расширен список проверяемых каталогов: `bin`, `bin\x64`, `cublas\bin` и вложенные местоположения `cublas64_13.dll` внутри **обнаруженного** CUDA Toolkit; официальный комплект cuBLAS в стандартных каталогах Python, а также локальная папка форка `E:\ai\Strata-Q4-Fork\.strata-runtime\cublas-13.3.0.5\nvidia\cu13\bin` (с поддержкой старого формата `nvidia\cublas\bin`). Весь диск и каталоги пользовательских моделей не сканируются.
2. Запускающий сценарий проверяет присутствие `cublas64_13.dll`, а при её отсутствии подтверждает импорт через `dumpbin`. Лишь при подтверждённом отсутствии cuBLAS разрешает адресную установку официального пакета NVIDIA. При отсутствии `dumpbin` установка вслепую не производится.
3. Добавлен `requirements-iq3s-cublas.txt` с фиксированной версией `nvidia-cublas==13.3.0.5` и официальным SHA-256 файла Windows x64 `065b944083560334e02299050979b7cfd91ec79e5fc5c23d602f7f35c0d1356c`. Пакет опубликован NVIDIA на PyPI (https://pypi.org/project/nvidia-cublas/13.3.0.5/); размер скачивания около 388 МБ. Используется `pip --require-hashes --only-binary=:all: --no-deps --no-cache-dir --target ...`. Обязательная проверка хеша не допускает подмены колеса.
4. Установка выполняется **только в папку форка**, сперва во временный каталог с уникальным идентификатором, затем после проверки DLL каталог переименовывается в постоянный. В случае ошибки удаляется только созданный текущим вызовом временный каталог. Существующая постоянная папка, данные пользователя, GGUF и системная CUDA не удаляются, не перезаписываются. Системный PATH не изменяется; пути расширяются лишь в окружении процесса запуска.
5. После восстановления набор каталогов и переменная PATH формируются заново, затем проверяется `strata.exe --help` **до** изменения RAM-диска. Поэтому при неудовлетворённой зависимости модельные данные не затрагиваются.
6. В корневом `START-IQ3S-RAM.ps1`, в обеих его копиях (папка персонального запуска и `tools/windows/q4-local-profiles`) и в `BUILD_AND_START_IQ3S.ps1` включён адресный режим `-RepairMissingCublas`. `GET-IQ3S-DIAGNOSTICS.ps1` намеренно сохраняет режим только диагностики — без загрузки/установки.
7. Настройки качества GSQ-RCO IQ3_S, PLE на R:, двух сегментов GGUF, квантования, контекста, MTP и параметров семплирования **не менялись**.

## Проверки в среде разработки

- Проверено совпадение трёх версий `START-IQ3S-RAM.ps1`, наличие файла SHA-256 и ссылок на новый параметр во всех точках вызова.
- Проверено, что основа архива сохранена целиком, добавлены только новые файлы и адресные исправления сценариев.
- **Отсутствует Windows/PowerShell в среде создания:** реальную загрузку 388-МБ пакета, выполнение PowerShell, запуск собранного `strata.exe` и ответ модели подтвердить нельзя. Отказ `0xC0000135` считается устранённым только после подтверждения на компьютере пользователя.

## Запуск пользователем после самостоятельной распаковки

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
Set-Location 'E:\ai\Strata-Q4-Fork'
try { & '.\START-IQ3S-RAM.ps1' } catch { Write-Host "Ошибка запуска: $($_.Exception.Message)" }
& '.\GET-IQ3S-DIAGNOSTICS.ps1'
try { Invoke-RestMethod 'http://127.0.0.1:8080/v1/models' -TimeoutSec 10 | ConvertTo-Json -Depth 8 } catch { Write-Host "API недоступен: $($_.Exception.Message)" }
```

При отсутствии cuBLAS автоматическая однократная загрузка официальной библиотеки требует доступа к `https://pypi.org/simple` и около 388 МБ сетевого трафика. Она не повторяется, если требуемая DLL уже обнаружена. Для анализа приложить текст PowerShell и `logs\iq3s\DLL_DIAGNOSTICS_LAST.txt`/`DIAGNOSTICS_LAST.txt` при неуспехе.

## Нерешённые задачи и риски

Подтвердить установку cuBLAS и прохождение `strata.exe --help` на Windows 10, затем загрузку `READY`, работу `/v1/models` и короткую генерацию через `/v1/chat/completions`. Если следующий сбой будет уже после загрузки DLL, анализировать новые журналы вместо изменения проверенных путей. В случае ограничений сети пользователь должен предоставить результат ошибки `pip`; никаких альтернативных/непроверенных DLL нельзя подмешивать.

**Состояние архива:** промежуточный; полный код проекта. Подтверждённого запуска в итерации 036 пока нет.
