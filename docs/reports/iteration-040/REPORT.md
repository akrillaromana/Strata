# Strata Fork — отчёт итерации 040

Дата: 12 октября 2026 года. Основа: полный архив `Strata-Fork-IQ3S-iteration-039.zip`. Результат: **промежуточная итерация**. Код изменён и выборочно проверен, но испытания PowerShell и браузера на пользовательской Windows ещё не выполнены.

## Задание и принятые ограничения

Пользователь потребовал калибровку **для всех моделей**, а не только GSQ-RCO IQ3_S; при запуске калибровщик должен спрашивать, какую модель настраивать. Веб-чат должен позволять копировать собственные сообщения и ответы одним нажатием. Нельзя ломать рабочие модели, менять автоматически IQ3_S, Q4, Q6, Q8, MTP, PLE, RAM-диск, системный Python и исходные настройки.

## Изменения по файлам

1. `TUNE-MODEL.ps1` — **новый общий интерфейс калибровки**. При запуске без `-Model` и `-ConfigPath` выводит нумерованный список профилей из корня проекта и двух папок пользовательских сценариев, затем спрашивает номер. При явном выборе допустим `-Model` (если имя однозначно) или `-ConfigPath`. Поддерживает профиль с произвольным `model_name`, запуск через порт `-Port`, проверку `/health`, `/v1/models`, `/props`, проверку точного пути активного GGUF и исполняемого файла; отвергает выбор незагруженной или другой модели. Работает с **текущим** сервером, не переключает модели. Подбирает долю PCIe и, если MTP включён, порог спекулятивного декодирования. Замеряет токены/с по `timings.predicted_per_second`, делает чередование кандидатов и контроль с базой. При недостатке 3% ускорения исходные значения сохраняются. Данные измерений сохраняются в `logs/autotune/`, а настройки — только по `-Apply` и только при выигрыше.
2. `TUNE-IQ3S.ps1` — совместимый ярлык к `TUNE-MODEL.ps1`, сохраняющий прежние параметры `-Apply`, `-Rounds`, `-MaxTokens`, `-MinGain`. Вместо отдельной ветки кода IQ3_S использует общую, не меняя данных GGUF.
3. `serve/server.py` — общий `model_autotune_args(cfg, args)` применяется внутри `engine_args` для **любой модели, работающей с `--native`**. Привязка по SHA-256 комбинации `model_name` и пути `--native`, плюс SHA-256 движка. Настройки хранятся в `model-autotune/<ключ>.json`. Проверки версии, модели, файла GGUF, движка, чисел от 0 до 1 и разрешённых флагов. При ошибках/неверной привязке используется оригинальный набор аргументов. Отказ без удаления файла: `autotune: false` в профиле или `STRATA_IGNORE_AUTOTUNE=1` в окружении запуска. Никакой старый файл не перезаписывается.
4. `START-IQ3S-RAM.ps1` и две пользовательские копии — добавляется `autotune = (-not $IgnoreAutotune)` к **создаваемому** профилю, чтобы прежний ключ отката отключал как старую настройку IQ3_S, так и новый общий механизм. Контракты PLE, MTP, GSQ-RCO, NVMe, RAM-диска, семплинга и размеров памяти не изменены.
5. `serve/web/app.js` — кнопка копирования добавлена **для сообщений пользователя** рядом с меткой времени. Кнопка ответа модели теперь доступна сразу после появления текста, даже во время потоковой генерации. Используется оригинальный текст записи `messages[i].text`, не HTML. Основной путь — Clipboard API; резервный для HTTP/LAN — `execCommand('copy')`, с проверкой возвращаемого значения. При отказе сообщается об ошибке, без ложного подтверждения. Сохранены обработчики удаления, истории диалогов, копирования кода и файлов.
6. `tools/test_model_autotune.py` — 6 самостоятельных тестов правильного применения/изоляции/отказа/добавления флага для калибровки.
7. `docs/reports/iteration-040/` — отчёт, инструкции и незавершённые задачи. Корневой `CONTINUE_PROMPT.md` обновлён.

## Замечания о безопасности и воспроизводимости

- Калибровка выбранной модели возможна только когда соответствующий сервер уже работает; автоматическая смена и загрузка GGUF **не реализована** намеренно, поскольку она могла бы нарушить RAM-диск и работу с другими моделями.
- Механизм подбирает два параметра, которые движок позволяет менять на уровне запроса. Отдельная полная офлайновая калибровка CPU-потоков, кэша VRAM и адаптивного PCIe с остановкой/перезапуском сервера **не выполнена**.
- `pcie_frac` может менять порядок/место вычислений, а значит немного менять ответы. `-Apply` требуется явно; никаких гарантий точного числового совпадения после изменения этих параметров не заявляется.
- Прежние файлы `IQ3S_AUTOTUNE.json` продолжают читаться старым запускающим сценарием в целях совместимости; новые рекомендации сохраняются отдельно по модели и имеют приоритет в общем сервере, если их привязка верна.
- Архив должен содержать проект непосредственно в корне, без обёрточного каталога, полный набор файлов.
