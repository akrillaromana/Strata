# Команды PowerShell для итерации 040

Пользователь **самостоятельно** распаковывает архив в `E:\ai\Strata-Q4-Fork`. Ниже нет команд поиска и распаковки.

## Если выбранная модель уже работает — второе окно PowerShell 7

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
Set-Location 'E:\ai\Strata-Q4-Fork'
& '.\TUNE-MODEL.ps1' -Apply
```

Появится список конфигураций с номерами и вопрос **«Какую модель калибруем?»**. Ввести номер конфигурации, соответствующей **уже запущенной** модели. Другие модели не будут загружены или переключены автоматически.

Пробный прогон **без применения**:

```powershell
& '.\TUNE-MODEL.ps1'
```

Для выбора точного профиля без вопроса (например, при повторной проверке):

```powershell
& '.\TUNE-MODEL.ps1' -ConfigPath 'E:\ai\Strata-Q4-Fork\strata-iq3_s-RAM.json' -Apply
```

Прежняя команда IQ3_S тоже поддерживается:

```powershell
& '.\TUNE-IQ3S.ps1' -Apply
```

Если результат принят, он вступит в силу при **следующем запуске выбранной модели**. Перед этим нужно остановить текущий сервер `Ctrl+C`. Движок пересобирать не требуется.

Для IQ3_S запуск со штатными настройками:

```powershell
& '.\START-IQ3S-RAM.ps1' -IgnoreAutotune
```

Для остальных моделей — запуск без применения индивидуальной калибровки (в том же процессе PowerShell):

```powershell
$env:STRATA_IGNORE_AUTOTUNE = '1'
# Затем запустить обычный сценарий выбранной модели.
# Чтобы вновь применять проверенную настройку:
Remove-Item Env:STRATA_IGNORE_AUTOTUNE -ErrorAction SilentlyContinue
```

## Веб-интерфейс

Обновите страницу Strata (при необходимости Ctrl+F5), откройте чат. Рядом с меткой времени **каждого** текстового сообщения есть значок копирования; нажмите один раз.

## Результат диагностики

Отчёты калибровки: `E:\ai\Strata-Q4-Fork\logs\autotune\<SHA-256>-LAST.json`.

Настройки, применяемые при следующем старте: `E:\ai\Strata-Q4-Fork\model-autotune\<SHA-256>.json`.

Отправьте конкретный отчёт и полный вывод PowerShell, если калибровка завершилась ошибкой.
