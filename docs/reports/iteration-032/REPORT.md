# Итерация 032 — исправление инициализации MSVC

## Причина
PowerShell 7.6.6 останавливался с сообщением `"""C:\Program" не является внутренней или внешней командой`. Причина — неправильные кавычки при вызове `VsDevCmd.bat` через `cmd /s /c`.

## Изменено
- `BUILD_AND_START_IQ3S.ps1`: инициализация MSVC через временный файл `_strata_msvc_environment.cmd`, содержащий корректный вызов `call "<VsDevCmd.bat>"`; переменные среды возвращаются в PowerShell, файл удаляется.
- Исправлен путь к `ninja.exe` после установки через Python: Ninja находится рядом с `python.exe` в каталоге `Scripts` виртуального окружения или в каталоге `Scripts` системного Python.
- Сохранены абсолютный корень `E:\ai\Strata-Q4-Fork`, генератор Ninja, архитектура sm_86 и журнал сборки.

## Дальнейшие шаги
1. Выполнить сборку на Windows 10 с CUDA 13.3.
2. При необходимости устранить ошибки конфигурации или компиляции.
3. Проверить RAM-диск R:, файлы модели IQ3_S, профили запуска, зависимости Python.
4. Подтвердить работу `/v1/models` и генерации через API.

Код обновлён, сборка и запуск на целевой системе не подтверждены. Архив промежуточный.
