## Запрос пользователя

Единые значения по умолчанию для всех рабочих профилей и уровней конфигурации:

- `pcie-frac = 0.26`;
- MTP `spec-min-p = 0.90`.

Автокалибровка может явно выбрать другое значение, но отсутствие применённого autotune/явного пользовательского переопределения должно возвращать именно к `0.26 / 0.90`.

## Что изменено

1. Все 22 активных MTP JSON-профиля и примера в корне, `PERSONAL_START_E_ai_Strata-Q4-Fork`, `tools/windows/q4-local-profiles` и `tools/windows/native-high-quant` приведены к `--pcie-frac 0.26` и `--spec-min-p 0.9`. Для JSON, где `--pcie-frac` отсутствовал, он добавлен.
2. В Q4_K_XL, Huihui Q4_K_XL, Q8_0 и IQ3_S запускателях одинаковые fallback/default значения: PCIe `0.26`, MTP `0.90`.
3. `setup.py` теперь генерирует новые конфиги сразу с `--pcie-frac 0.26 --spec-min-p 0.9`.
4. `tools/calibrate.py` сбрасывает непринятую/устаревшую калибровку к `0.26 / 0.90`, а не к старому `auto / 0.5`.
5. В main и SYCL `generate.cpp` прямые значения по умолчанию установлены в `pcie_frac=0.26` и `spec_min_p=0.90`. Явные CLI/HTTP tune-параметры сохраняют приоритет.
6. Golden-конфиги setup перегенерированы под новый продуктовый default.
7. Статические тесты персональных профилей теперь отдельно требуют `0.26 / 0.90`.
8. Сетка `TUNE-MODEL.ps1` не урезана: MTP `1.0` по-прежнему обязательно тестируется, но стартовый/default MTP теперь `0.90`.
