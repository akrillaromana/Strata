# Задачи после итерации 050

1. На Windows проверить Q8_0, IQ3_S, Q4_K_XL и Huihui: без применённого autotune строка запуска должна показывать PCIe `0.26` и MTP/spec-min-p `0.90`.
2. Проверить `TUNE-MODEL.ps1 -Apply`: кандидаты могут отличаться от default, включая обязательный MTP `1.0`; непринятый результат не должен менять baseline `0.26 / 0.90`.
3. Подтвердить, что root/PERSONAL_START JSON не переписываются во время запуска; runtime JSON создаются только в `logs`.
4. Продолжить стресс-тест HTTP/SSE и адресный перенос полезных изменений Strata 0.1.43.1.
5. Не возвращать SHA-проверки файлов; идентичность файлов по пользовательскому правилу — точное имя + точный размер.
