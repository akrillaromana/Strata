# Оставшиеся задачи после итерации 047

1. На PowerShell 7.6.6 проверить `tools/TEST-MODEL-LAUNCHERS.ps1`, `tools/TEST-CONFIG-IMMUTABILITY.ps1` без запуска модели и без изменения R:; устранить ошибки, если обнаружатся.
2. Запустить Q8_0 на существующем R: с меткой `RamDisk`. Убедиться, что том распознан по известным файлам или AIM, не отформатирован, этапы PLE/RAM продолжаются до READY.
3. Проверить контрольными суммами, что вручную изменённый `strata-unsloth-q8_0.json` в корне и личный JSON не меняются при старте. Изменения в `--spec`, `--kv`, `--max-context`, `--pcie-frac` и поле `sampling` должны сохраняться в источнике.
4. После Q8 READY подтвердить строку применения проверенного профиля `pcie_frac=0.2`, `spec_min_p=0.9` и реальную генерацию через API.
5. Повторить корректность runtime JSON для IQ3_S, Q4_K_XL, Huihui и проверить переключение моделей с сохранением пользовательских параметров.
6. Улучшить полную аппаратную калибровку потоков CPU/экспертного кэша; отдельные длинные воспроизводимые измерения Q8_0 и стабильности качества.
7. Опционально исследовать механизм автонастройки общего `setup.py` (отдельный режим), если он перезаписывает собственные профили; пользовательские личные запуски уже используют новую read-only схему.
