# Итерация: устранение жёсткой зависимости IQ3_S от .venv

## Диагностика

На строке 15 файла `START-IQ3S-RAM.ps1` был задан исключительно `$Root\.venv\Scripts\python.exe`, а в начальной проверке этот путь требовался без альтернатив. На пользовательском компьютере файл отсутствует, поэтому выполнение прекращается до загрузки GGUF.

## Изменения

- В обоих исходных экземплярах `START-IQ3S-RAM.ps1` введена функция `Resolve-StrataPython`.
- Сохраняется приоритет локальной среды `.venv`; если её нет, проверяются приложения `python.exe` и `python3.exe` из `PATH`.
- Проверяется реальная возможность запуска Python и версия не ниже 3.10; алиасы без работоспособного интерпретатора пропускаются.
- Исполняемый файл Python более не участвует в списке безусловно необходимых путей: вместо этого предусмотрена отдельная диагностическая ошибка.
- Логика GGUF, переноса PLE, создания RAM-диска, настройки качества и сохранения пользовательской конфигурации не менялась.

## Проверка и ограничения

Статически проверен участок исходного кода. Windows/PowerShell и установленные компоненты пользователя здесь недоступны; полноценный запуск не проверен. Если Python есть только через `py.exe` или зависимости выбранной среды отсутствуют, потребуется настройка Python. Следующие недостающие обязательные пути будут показаны независимо.

## Следующая итерация

Проверить запуск на Windows и доступность зависимостей выбранного Python, затем разбирать следующие сообщения диагностики, если они появятся. Проверить доступность `lib_dirs` NVIDIA без навязывания несуществующих директорий.
