# Strata Fork — итерация 049 (13.10.2026)

**Статус: промежуточный полный архив.** Основа — полный проект итерации 048 с наложением актуального пользовательского `Strata-Q4-Fork.zip`, чтобы не потерять ручные конфигурации.

## Запрос пользователя

1. `MTP/spec-min-p = 1.0` обязан участвовать в калибровке любой модели.
2. Исправить `BENCHMARK-MODEL.ps1`, который падал на строках вида `$i:` в PowerShell 7.6.6.
3. Полностью убрать вычисления SHA из исполняемых путей. Для файлов правило пользователя: **точное имя + точный размер в байтах совпали — файл считается тем же**.
4. Ручные JSON пользователя не переписывать и не заменять автоматически.

## Что сделано

### Калибровщик

`TUNE-MODEL.ps1` штатно перебирает MTP: `0.3, 0.5, 0.7, 0.75, 0.9, 1.0`. Значение 1.0 не является специальным для Q8 и будет проверяться для любой выбранной модели с MTP.

На предоставленном пользователем Q8_0 прогоне MTP=1.0 дал около 12.9–13.3 ток/с и оказался хуже MTP=0.9 (~14.8–15.6 ток/с в той же серии). Это не повод удалять 1.0 из сетки: другие модели/сборки могут вести себя иначе.

Привязка `model-autotune` переведена с SHA движка/модели на имя и точный размер файла в байтах. Формат профиля поднят до версии 2. Старые SHA-привязанные профили не вычисляются и автоматически не подбираются.

### Удаление SHA

Удалены активные SHA-вычисления из:

- Q8/IQ3_S/Huihui запускателей и проверок RAM-копий;
- `setup.py`, MTP fetch/pack и Strata pack;
- Q8 pack provenance, `iq_pack.py`, donor audit;
- автокалибровки модели и проверки `strata.exe`;
- conversation-cache диагностических утилит;
- vision cache сервера (ключом служат точные нормализованные байты изображения, без хэша);
- старых benchmark-скриптов, где ранее сохранялся digest запроса.

Для файлов используется только точное имя и точный размер в байтах. Это намеренно **не криптографическая проверка**: разные данные одинакового имени и размера по требованию пользователя считаются одинаковыми.

В тестовых файлах остаются только отрицательные проверки строк `SHA/Get-FileHash`, чтобы не допустить возврата этих вычислений. Они сами ничего не хэшируют.

### Пользовательские конфигурации

Рабочая база создана как полный 048 + наложение актуального пользовательского `Strata-Q4-Fork.zip`. Проверены все 16 JSON из пользовательского архива: содержимое в рабочем дереве совпадает байт-в-байт. Включая дополнительные `strata-unsloth-q8_0 — копия.json`.

Запускатели продолжают создавать отдельный runtime JSON в `logs/<model>/...`; root/PERSONAL_START JSON используются только как вход. Автотюнинг также не переписывает исходный JSON.

### Benchmark

В `BENCHMARK-MODEL.ps1` исправлены обе строки PowerShell с `$i:` на `${i}:`. Статический поиск по всем PS1 не обнаружил других обращений `$переменная:` вне специальных областей `$env:` и т.п.
