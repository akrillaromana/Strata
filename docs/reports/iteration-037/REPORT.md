При этом в новом журнале **нет ответа на реальный запрос генерации**. Показанные в сохранённом предыдущем журнале показатели 30.0 и 36.3 токена/с относятся к старой сессии и не доказывают производительность нынешней сборки.

## Изменения в исходниках проекта

Добавлен только отдельный корневой файл `VERIFY-IQ3S-API.ps1`. Файлы C++, CUDA, Python и существующий сценарий запуска не изменены. Проверка:

1. Читает управляемую конфигурацию `E:\ai\Strata-Q4-Fork\strata-iq3_s-RAM.json` и ожидаемое имя модели.
2. Поддерживает `api_key`, если он задан в локальной конфигурации, и не печатает его.
3. Проверяет `GET /health`: реальный загруженный сервер.
4. Проверяет `GET /v1/models` и соответствие идентификатора модели профилю IQ3_S.
5. Выполняет настоящий `POST /v1/chat/completions` с `stream=false`, отключёнными размышлениями в рамках **только проверочного запроса**, `max_tokens=128`, `reasoning_budget_tokens=0`, `temperature=0`.
6. Проверяет непустой текст в `choices[0].message.content`, записывает статус и характеристики в `E:\ai\Strata-Q4-Fork\logs\iq3s\VERIFY_IQ3S_API_LAST.txt`.
7. Не изменяет RAM-диск, кэш, модель, конфигурацию, порт, параметры семплирования других запросов и не останавливает сервер. При ошибке возвращает исключение с точной стадией.

Поскольку сервер доступен по `0.0.0.0:8080`, а журнал фиксирует отсутствие API-ключа, проверочный сценарий предупреждает об опасности доступности со стороны сети, **не меняя выбранную пользователем настройку**.

## Команды на компьютере пользователя

Пользователь самостоятельно распаковывает полный архив 037 прямо в `E:\ai\Strata-Q4-Fork` без дополнительного каталога. После этого вводит:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
Set-Location 'E:\ai\Strata-Q4-Fork'
& '.\VERIFY-IQ3S-API.ps1'
```

При остановленном сервере **отдельно** сначала `& '.\START-IQ3S-RAM.ps1'`, затем проверку. Повторная сборка движка не нужна. При ошибке приложить `logs\iq3s\VERIFY_IQ3S_API_LAST.txt` и последние журналы `server-*.stderr.log`, `engine-*.stderr.log`. Не повторять загрузку модели ради одной проверки, если она уже запущена.
