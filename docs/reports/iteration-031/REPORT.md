# Итерация 031 — исправление настройки CUDA

## Основание
На Windows PowerShell 7.6.6, CUDA 13.3, MSVC 19.44 и GPU sm_86 команда CMake с генератором Visual Studio 17 2022 завершалась сообщением `No CUDA toolset found` при `enable_language(CUDA)`. Также первоначальный блок распаковки ошибочно предполагал нахождение архива в `Downloads`.

## Выполнено
- Сценарий `BUILD_AND_START_IQ3S.ps1` переписан для генератора Ninja без зависимости от CUDA BuildCustomizations Visual Studio.
- MSVC инициализируется через `VsDevCmd.bat`, найденный через `vswhere.exe`.
- Путь CUDA Toolkit определяется через найденный `nvcc.exe`; архитектура определяется NVIDIA-SMI.
- Ninja используется из PATH или устанавливается через pip установленного Python.
- Выделен отдельный каталог сборки `build-iq3s-ninja-release`.
- Результирующий `strata.exe` размещается в `engine`.
- Файлы стартового профиля обновляются из каталога профилей независимо от наличия старых копий в корне.
- Лог работы пишется в `BUILD_AND_START_IQ3S.log`.

## Осталось
- Проверить компиляцию на Windows с CUDA 13.3 и MSVC.
- Проверить доступность моделей, RAM-диска, зависимостей Python и запуск сервера.
- При ошибках использовать полный журнал `BUILD_AND_START_IQ3S.log`.

## Статус
Исходники изменены. Полная сборка и запуск на целевой системе не проверены. Архив содержит весь проект и не содержит дополнительного корневого каталога.
