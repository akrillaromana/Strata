# Команды PowerShell для итерации 041

Архив распаковывает сам пользователь. **Не** предоставлять команды поиска, выбора, распаковки ZIP; архив без верхней папки. Компиляция движка не требуется.

Сначала в первом окне PowerShell должна работать выбранная модель (IQ3_S либо другая, которую нужно калибровать). Во втором окне:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
Set-Location 'E:\ai\Strata-Q4-Fork'
& '.\tools\TEST-TUNE-MODEL.ps1'
& '.\TUNE-MODEL.ps1' -Apply
```

При успешном прохождении проверки выбрать в списке конфигурацию **запущенной** модели. Приложить вывод и отчёт `E:\ai\Strata-Q4-Fork\logs\autotune\<ключ>-LAST.json`. Измерения выполняются без изменения запущенной модели; сохранённые параметры будут использоваться только после следующего старта этого профиля.

Для явного выбора определённого файла конфигурации без меню (например, совместимого IQ3_S):

```powershell
& '.\TUNE-MODEL.ps1' -ConfigPath '.\strata-iq3_s-RAM.json' -Apply
```

Если необходимо только измерить, не записывая рекомендации:

```powershell
& '.\TUNE-MODEL.ps1'
```

Не запускать пересборку `strata.exe` и не переносить файлы модели. Если сервер не запущен, запустить его привычным профилем в отдельном окне, дождаться READY, затем выполнить калибровку.
