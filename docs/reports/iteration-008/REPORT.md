## Реализовано

1. В веб-панели Sampling теперь есть режимы **Text / JSON object / JSON Schema**, имя схемы и редактор JSON Schema. Контент схемы проходит локальную проверку формы, размера, вложенности и запрета внешних `$ref` до отправки HTTP-запроса. Некорректный формат не записывает несостоявшийся запрос в историю чата.
2. Выбранный режим передаётся в фактическом `POST /v1/chat/completions` как `response_format`. При активном JSON-режиме MCP не запускается, поскольку сочетание tools и structured output не поддерживается сервером. Без JSON-режима запросы остаются обычными.
3. Схемы сохраняются в именованных browser-local sampling presets; переносимый формат расширен до **версии 3** с автоматической миграцией версий 1 и 2 (`stop` сохраняется). Прежние локальные настройки читаются с default `text` и не стираются.
4. В `serve/structured.py` исправлена **опасная деградация проверки `json_schema`**: если пакет `jsonschema` отсутствует, сервер теперь выдаёт HTTP 400 **до загрузки/генерации** вместо обманчивой проверки лишь на JSON-объект. JSON object по-прежнему использует только Python stdlib. В зависимости сервера добавлен закреплённый валидатор и его зависимости.
5. На сервере ограничены размер и глубина схемы, имя, запрещены внешние ссылки; старое поведение OpenAI Chat и Responses для валидных схем сохранено. Буферизованный структурированный SSE по-прежнему отправляет содержание лишь после проверки законченного JSON.
6. Обновлены изолированные браузерные проверки предустановок/системных инструкций и добавлена проверка взаимодействий нового режима.

## Точные ограничения

**Constrained token decoding НЕ реализован.** Режим работает методом `prompt_and_validate` и выдаёт ошибку при невалидном результате, а не гарантирует синтаксически правильный токен на каждом шаге. Это честное состояние: нельзя выдавать валидацию за нативную генерацию по грамматике. Стриминг буферизуется до успешного полного ответа. При отключённом пакете `jsonschema` schema-запрос отклоняется. Ограничено корневое `type: object`, 32 уровня вложенности, 64 KiB серверной схемы. JSON-режимы с MCP несовместимы.

JSON Schema через Anthropic `output_config.format` ещё не интегрирован (там сохранены старые правила API). Полная нативная реализация ограниченного декодирования должна быть отдельной задачей с контролем токенизатора и грамматики, не смешивать её с проведённой валидацией. Настоящие GPU/Windows тесты **отложены по прямому распоряжению пользователя**.
