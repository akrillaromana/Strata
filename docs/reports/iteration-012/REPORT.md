## Фактические изменения

- Плоский комплект `PERSONAL_START_E_ai_Strata-Q4/` для персонального пути `E:\ai\Strata-Q4`: Q4_K_XL Unsloth, Huihui Q4_K_XL, IQ3_S и сохранённые оригинальные JSON для Q8_0 (legacy) и Q4 non-RAM.
- `tools/windows/q4-local-profiles/` содержит тот же комплект; пользовательские BAT/PS1/JSON побайтово идентичны. Корневые `START-HERE.bat` оригинала не заменяются.
- В `START-Q4-RAM.ps1` и `START-IQ3S-RAM.ps1` исправлено расхождение с последними JSON: `--spec-min-p` равен `0.75`. Обновление JSON сохраняет явно заданные `sampling`, `repeat_stop_tokens` и дополнительные серверные ключи, при необходимости создаёт `.bak` и не затирает повреждённый JSON.
- В `START-HUIHUI-Q4-RAM.ps1` сохранена новая логика `sampling` и `repeat_stop_tokens` из пользовательского архива **и** восстановлены проверки SHA-256 копии PLE и индекса pack из версии 011.
- `strata-huihui-ud-q4_k_xl-RAM.json`: сохранены последние личные параметры `sampling`, `repeat_stop_tokens=64`, RAM-пути и `--spec-min-p 0.5`.
- В статическом `strata-unsloth-ud-q4_k_xl.json` `reasoning_budget_tokens` перенесён из неподдерживаемого аргумента `strata.exe` в серверное поле верхнего уровня.
- `README.md` и `README_RU_CUSTOM.md` предупреждают, что это персональный форк с фиксированными путями, не рекомендованный к использованию как есть другими людьми.
- Добавлен offline Python-тест 8 проверок путей, совпадения двух комплектов, опций, моделей и исключения GGUF/исполняемых файлов/логов.

## Ограничения

**На E: файлы не изменялись, модели и сервер не запускались**. Все утверждения — о кодовой базе. Для настоящей гарантии работы потребуется отдельный эксплуатационный этап по просьбе пользователя.

Из пользовательского Q8 JSON: `--ple-gguf R:\q8-ple\...IQ4_NL.gguf`. Это смешанная конфигурация Q8_0 + IQ4_NL PLE, **не** требуемый native Q8_0 n-gram. Полноценная поддержка native Q6_K/Huihui Q8_0 и перенос новых модулей 0.1.41 продолжаются.

Предварительные проверки не включают PowerShell parser от Microsoft: PowerShell в контейнере отсутствует. Произведён статический анализ, Python-тесты профилей и сопоставление с пользовательскими исходниками.
