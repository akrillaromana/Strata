# Следующие задачи

1. На Windows/RTX 3060 подтвердить последовательную генерацию Q8_0 (6+ запросов), а также IQ3_S/Q4_K_XL; собрать `/status` и конец реального stderr, если снова прекращается приём.
2. Проверить разные сценарии отмены/потери соединения, SSE и внешний API-клиент с большим/увеличивающимся контекстом без повреждения состояния движка.
3. Проверить распознавание тома RAM-диска с пустой меткой в реальном AIM Toolkit. Не ослаблять требование идентификации тома.
4. Запустить `tools/TEST-MODEL-LAUNCHERS.ps1` и `tools/TEST-CONFIG-IMMUTABILITY.ps1` в PowerShell 7.6; сравнить SHA-256 пользовательских JSON до/после фактического старта.
5. Сравнить длительные бенчмарки до/после изменений для IQ3_S, Q8, Q4 и Huihui. Никакие +15% на основе этой серверной итерации не обещаются.
6. Из 0.1.43.1 последовательно изучить исправления слотов, cancel при image encoding, recover/timeout, session-save и новые CUDA-оптимизации; переносить выборочно после тестов.
7. Проверить BAT в Windows, сценарии Python без `.venv`, пути E:/R: и авторизацию API с заданным `api_key`.
8. Для длительных стресс-тестов добавить параллельные клиенты и тесты SSE-клиентского отключения при реальном GPU.
