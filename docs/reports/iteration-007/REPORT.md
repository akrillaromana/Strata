# Strata Custom v0.1.39 — отчёт по итерации 007

Дата: 10 октября 2026 г. Исходная точка: полный архив итерации 006 и опубликованный пользователем HEAD `bb4b6ff` ветки `strata-v0.1.39-custom`.

## Цель

Закончить переносимую историю диалогов без потери вложений. Эта итерация **только по исходникам**; сборка CUDA, запуск реальной модели и установка на компьютер пользователя не выполнялись.

## Изменено

- `serve/web/chat_sessions.js`: переносимый JSON-документ `strata-chat-history`, версия 1; экспорт всех бесед с ID, активным выбором, сообщениями, временем, рассуждениями, текстом ошибок, результатами инструментов, вложенными файлами и встроенными изображениями; импорт с валидацией и без скрытого изменения текущих данных; ограничение 32 МиБ, 100 чатов и исключение посторонних полей.
- `serve/web/app.js`: исправлен `chatCopy()`: сохранение содержимого файлов и изображений вместо одного имени; кнопки экспорта/импорта; подтверждение перед заменой хранилища, запись до обновления UI; запрет операций при активной генерации; отдельная резервная копия сырого локального JSON для восстановления повреждённых данных. Отказ от SVG и прочих неподдерживаемых типов при прикреплении нового изображения.
- `serve/web/index.html`: три кнопки истории — `Export all`, `Import all`, `Raw backup`; скрытое поле файла JSON.
- `serve/web/test_chat_sessions.js`: семь новых сценариев переносимой истории, сохранения вложений/результатов инструментов и враждебных архивов.
- `serve/test_server.py`: проверка доставки необходимых контролов и модуля истории через веб-сервер.

## Ограничения и честное описание

- Размер переносимого JSON-архива ограничен 32 МиБ. Браузер обычно ограничивает `localStorage` отдельной, возможно меньшей квотой: попытка сохранить большой файл или изображение может завершиться ошибкой, о которой UI сообщит. Данные не должны незаметно заменяться именами файлов.
- Предыдущие версии уже могли сохранить вложение только по имени; из таких прежних записей утраченное содержимое автоматически восстановить невозможно. Новое сохранение предотвращает дальнейшую потерю.
- Экспорт истории может включать **приватные сведения и секреты, находящиеся в сообщениях, текстах вложений и результатах инструментов**. Экспорт не включает настройки API или пути к модели как отдельные поля. Пользователь предупреждается до экспорта.
- `Raw backup` сохраняет байты существующего локального JSON, в том числе повреждённые. Этот файл не импортируется автоматически как штатный архив: восстановление требует отдельного решения.
- Импорт заменяет весь набор бесед после подтверждения. Сначала следует сохранить свою историю. При отказе формата либо ошибке записи в localStorage текущие видимые данные не изменяются.
- Не путать кодовую завершённость этой **отдельной функции** с завершённостью всего форка. Нативный Q6_K / Huihui Q8_0 и другие задачи остаются в работе.
