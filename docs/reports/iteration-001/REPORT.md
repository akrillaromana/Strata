## Точная инвентаризация отличий

Пять изменённых относительно исходников файлов:

- `README.md`: пользовательский файл заменил официальную главную документацию инструкцией по диагностике. **Не перенесён поверх upstream**, полезное содержание отражено в отдельной документации.
- `START-HERE.bat`: заменён стандартный установщик на сценарий для единственной локальной Q4. **Не перенесён поверх upstream**.
- `serve/server.py`: дополнительный приём `reasoning_budget_tokens` из cookie веб-интерфейса и диагностическое сообщение. Перенесено с сохранением существующих приоритетов.
- `serve/web/index.html`: визуальное поле управления бюджетом рассуждений; переносится без встроенного стороннего кода.
- `src/core/native_dense.cpp`: проверка первичного и дополнительных шардов GGUF Huihui, включая повторение `general.architecture`. Перенесено.

Дополнительно из `huihui-compiled-source` перенесён расширенный `tests/core/native_dense_ple_key_test.cpp`: тест повторяющихся полей архитектуры и ошибок `split.*`. `tests/core/gguf_split_test.cpp` совпал с базовой версией и не требовал изменений.

21 локальный профиль / инструмент из корня рабочей установки Q4 перенесён в `tools/windows/q4-local-profiles/`. Ещё 2 экспериментальных PLE-сценария сохранены отдельно в `tools/windows/experimental-ple/`. Они не используются системой сборки по умолчанию.

## Исключённые файлы и причины

- `third_party/llama.cpp/` (включая вложенный `.git`, более 160 МБ в распакованном снимке): сторонняя зависимость, управляется CMake/FetchContent и не должна становиться частью fork.
- `engine/`, `.venv/`, `build/`, бинарные веса, GGUF, пакеты, RAM-копии: зависимые от конкретного компьютера сборочные данные или большой закрытый пользовательский ресурс.
- `backups/` и старые `docs/reports` локальной Q4: состояние конкретной установки, не часть приложения.
- `PATCH-STRATA-WEB-REASONING-BUDGET.ps1`: прежний одноразовый патчер, в кодовой ветке уже содержится результат изменений; повторный запуск способен испортить её.
- Конфигурация отдельного экспериментального `Q8_0`: не переносилась как профиль текущей Q4, поскольку предназначена для отдельного форка/движка.
- `strata-unsloth-ud-q4_k_xl.json` из локального снимка: ранее встречался неподдерживаемый аргумент `--reasoning_budget_tokens` на уровне движка, потому оставлен вне переносимого набора.
- `README.md` и `START-HERE.bat` upstream сохранены, чтобы универсальный процесс установки не стал зависеть от дисков E:/R: и AIM Toolkit.

## Проведённые проверки

- ZIP-архив пользователя успешно проверен при распаковке.
- Разница оригинального и изменённого C++-файлов рассмотрена вручную: точечное изменение алгоритма `split.*`.
- Изменение сервера рассмотрено вручную: один ограниченный участок обработки API-запроса.
- Сценарий браузера компилируется в Node.js (`vm.Script`).
- Синтаксис Python `serve/server.py` и локальных Python-утилит проверен (`py_compile`).
- Унаследованный `TEST-PREPARE.py` продвинулся через несколько случаев, но не завершился в предоставленном интервале. Его нельзя считать полностью пройденным; нужна отдельная диагностика времени выполнения.
- **Компиляция C++/CUDA этого итогового архива не выполнялась в контейнере из-за отсутствия NVIDIA CUDA.** В предшествующем реальном запуске пользователь уже собрал исправление на RTX 3060 и сообщил `2/2` успешных CTest-проверок, а также показал журнал работы Huihui на Strata-Q4.
