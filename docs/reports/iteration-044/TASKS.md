# Оставшиеся задачи — итерация 044

1. На Windows подтвердить актуальную версию `044` через `STRATA_ITERATION.txt` и `Get-Command .\START-Q8-RAM.ps1`.
2. Выполнить `tools/TEST-MODEL-LAUNCHERS.ps1` из обновлённого комплекта. Ожидается явная проверка `-PreparePack` и `-AllowBf16Conversion` для трёх Q8-сценариев и равенство двух внутренних копий.
3. В PowerShell 7 с правами администратора, после остановки других моделей, проверить `START-Q8-RAM.ps1 -PreparePack -AllowBf16Conversion` на настоящих шести GGUF. Если отсутствуют GGUF, MTP, экспертный профиль или библиотеки Python — зафиксировать действительную ошибку, не заменять веса.
4. Проверить создание собственного Q8-пакета и происхождение по SHA-256, не допуская подмены PLE `Q8_0` или существующих пакетов Q4/IQ3_S.
5. По журналам `CHECK-STRATA-RAM-DISK.ps1` диагностировать возможное оставшееся устройство AIM с отсутствующей буквой `R:`. Не удалять устройство и не форматировать его автоматически.
6. Подтвердить запуск Q8 до `READY`, `/v1/models`, реальную генерацию и качество; отдельно Q4/Huihui без `.venv`.
7. Протестировать аппаратную калибровку остальных моделей и длительную устойчивость с MTP/PLE/общим RAM-диском. Избегать изменения качества ради непроверенных процентов ускорения.
8. При следующей итерации сохранить всю исходную базу, русский отчёт, корневой подробный `CONTINUE_PROMPT.md`; выдавать ZIP без верхней папки. Развивать только обнаруженные в исходниках или логах дефекты.
