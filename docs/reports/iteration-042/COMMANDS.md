# Команды Windows PowerShell 7.6.6 — итерация 042

Пользователь **самостоятельно распаковывает** архив в `E:\ai\Strata-Q4-Fork`. Команды распаковки не нужны. Запускатели для RAM-диска выполняются в PowerShell с повышенными правами. Все команды вводить из корня форка.

## Проверка синтаксиса без запуска модели

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
Set-Location 'E:\ai\Strata-Q4-Fork'
& '.\tools\TEST-MODEL-LAUNCHERS.ps1'
```

## Запуск Q4_K_XL (не требует локальной .venv)

```powershell
& '.\START-Q4-RAM.ps1'
```

## Запуск Huihui Q4_K_XL

```powershell
& '.\START-HUIHUI-Q4-RAM.ps1'
```

## Запуск оригинальной Unsloth Q8_0

```powershell
& '.\START-Q8-RAM.ps1'
```

Если исходники Q8 находятся не в стандартных путях, укажите их явно:

```powershell
& '.\START-Q8-RAM.ps1' -ModelsDirectory 'E:\ai\models\unsloth\Qwen3.8-Flash-Next-GGUF' -PackSource 'E:\ai\Strata-data\packs\unsloth-q8_0'
```

В примере путь пакета — **предположение**, а не подтверждённая существующая папка. Если фактическое расположение иное, подставить настоящий путь; подстановка пакета от Q4/IQ3_S запрещена.

Любая модель использует порт 8080. **Прежде чем переключить модель, остановите предыдущую через Ctrl+C в её терминале.** Фоновый режим — `-Detached`.

## Калибровка любой загруженной модели во втором окне

```powershell
& '.\TUNE-MODEL.ps1' -Apply
```

Для контрольного прогона без сохранения убрать `-Apply`. Кандидат применяется только при фактическом превышении полного неокруглённого порога 3%.
