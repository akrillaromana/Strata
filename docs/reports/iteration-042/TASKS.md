# Оставшиеся задачи после итерации 042

1. На Windows 10 с PowerShell 7.6.6 выполнить проверку синтаксиса `tools/TEST-MODEL-LAUNCHERS.ps1`.
2. Подтвердить запуск `START-Q4-RAM.ps1` при отсутствии `.venv`, появление живых сведений о запросах/префилле/скорости и успешность API.
3. Подтвердить аналогичный запуск Huihui и отсутствие регрессий SHA-256 проверки его нативного пакета.
4. Проверить наличие оригинальных шести Q8_0 GGUF и отдельного Q8-пакета с `tokenizer` на пользовательском компьютере. Если нет — подготовить отдельный пакет без переквантования чужой модели.
5. Выполнить `START-Q8-RAM.ps1`: проверить Q8_0 PLE, размещение на RAM-диске, правильную загрузку native/спекулятивного MTP, фактический API-ответ и скорость. При появлении ошибки исправлять по её фактическому сообщению, не подменять таблицу на IQ4_NL.
6. Проверить, как выбранные результаты `TUNE-MODEL.ps1` применяются после перезапуска каждого из Q4/Q8/Huihui-профилей; отдельно проверить запрет применения настроек чужой модели, откат и контроль SHA-256 двигателя.
7. Дополнить калибровку потоков CPU, экспертного кэша VRAM и параметров предварительной обработки с безопасной изоляцией результатов для разных моделей. Пока реализован подбор PCIe/MTP у загруженной модели.
8. Сопоставить по парным измерениям скорость GSQ-RCO IQ3_S до/после выборочных изменений Strata 0.1.43, не считать чужие +15% результатом для нашего GGUF.
9. Проверить копирование пользовательских и ассистентских сообщений в веб-чате в реальном браузере (изменения 040).
10. Провести итоговую компиляцию/регрессии всех моделей; после этого — финальный аудит всего донора Strata 0.1.43 и собственных оптимизаций.
