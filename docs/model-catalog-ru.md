# Дополнительные модели Strata — каталог MODEL-CATALOG

Список составлен по присланному владельцем полному выводу `E:\ai\models` от 18 октября 2026 года. Источником является `MODEL-CATALOG.json`. Программа не изменяет этот файл, GGUF, исходные JSON существующих запускателей и незавершённые `.part`.

## Что уже сделано

- В каталоге 8 дополнительных вариантов Qwen3.8-Flash-Next (`qwen4exp`) и 5 вариантов Qwen3.6-35B-A3B (`qwen35moe`).
- Для готовых Flash-Next предусмотрено получение собственного native pack через существующий проверенный `tools/iq_pack.py`.
- Поддерживаются ещё скачивающиеся Swift: до завершения сегментов запуск и подготовка не производятся.
- Временный JSON сервера создаётся только в `logs\catalog\ИМЯ\`, а не вместо пользовательского файла.
- Параметры: PCIe 0.09, MTP threshold 0.90, `--spec 4`, параллельность 2, контекст 262144, KV int8, KV resident 32768, reasoning budget 10240. Резерв резидентных экспертов 80 GiB; для Huihui Q8 — 120 GiB.
- Для дополнительных профилей используется GGUF непосредственно на диске `E:` и подготовленный pack на `E:`. В отличие от специальных Q4/Q6/Q8/IQ3 запускателей, автоматического переноса PLE на `R:` **пока нет**. Не следует приписывать этому режиму скорость RAM-варианта.

## Команды PowerShell 7

После самостоятельной распаковки полного архива в `E:\ai\Strata-Q4-Fork`:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
Set-Location 'E:\ai\Strata-Q4-Fork'
& '.\START-CATALOG-MODEL.ps1' -List
```

Подготовить native pack и запустить готовую модель SC117 RCO IQ3_S:

```powershell
& '.\START-CATALOG-MODEL.ps1' -Name 'sc117-rco-iq3s' -Prepare
```

Для некоторых не-IQ3 квантований подготовка может потребовать преобразования небольших проекций в BF16. Эта операция округляет исходные веса, поэтому отключена по умолчанию. Если подготовка завершилась отказом именно по формату BF16, сначала изучите сообщение: промежуточный каталог сохраняется, никакой автоматической очистки нет. Для нового чистого запуска можно указать `-AllowBf16Conversion` после разбора незавершённого каталога.

Остановить работающую модель: `Ctrl+C`. Для другой модели нужно остановить предыдущую: порт 8080 и движок не освобождаются принудительно.

## Что пока невозможно запустить

Пять записей 35B-A3B, включая оригинал Unsloth UD-Q8_K_XL и HauhauCS uncensored Q4_K_P, пока имеют состояние ожидания. В нативном движке форка есть жёсткая проверка архитектуры `qwen4exp`, а 35B использует `qwen35moe`. В донорском Strata 0.1.45 есть отдельный движковый путь для 35B, однако его нельзя заменить одним конфигом, не перенеся вычислительное ядро, загрузчик, подготовку памяти, декодирование и испытания.

Файла *uncensored 35B Q8_K_XL* в переданном списке **не обнаружено**. Для него необходим фактический путь и GGUF, а также нативная поддержка `qwen35moe`.

Также в папках есть Qwen3.8-27B (плотная), Qwen3.5-9B, Gemma 4 и Qwen2.5-Coder. Движок этого форка для них не предназначен: они не зарегистрированы как готовые модели, чтобы не выдавать ошибку архитектуры за рабочий запуск.

## Что проверить на Windows

1. `-List` должен показать восемь поддерживаемых семейств и пять ожидающих 35B.
2. Подготовка SC117/Alesha IQ3_S должна закончиться созданием `index.txt`, `native_experts.txt`, `tokenizer\chat_template.jinja` в новом каталоге pack.
3. После запуска запросите `http://127.0.0.1:8080/v1/models` и сделайте короткий запрос с MTP и два параллельных запроса.
4. Сравните два значения PCIe (0 и 1) через `VERIFY-RUNTIME-TUNE.ps1` на собранном движке.
5. Измерьте скорость по сравнению со специализированным RAM-запускателем. Для нового каталога её нельзя заранее гарантировать.
