## 5. Нерешённые задачи — приоритет для следующих итераций

### P0

1. **Настоящий token-level constrained decoding** для JSON Schema в C++/CUDA с tokenizer-aware grammar, UTF-8, вложенными объектами/массивами, потоком и синхронным API. Строго отделить от present prompt-and-validate; если полный режим невозможен — в документации честно сохранить ограничение.
2. **Anthropic output_config.format** (где применимо к договорённости API), совместимость с Anthropic streaming и stop, без ложного принятия схемы, которую сервер не проверяет. Общий набор серверных форматов для OpenAI Chat/Responses/Anthropic.
3. **Q6_K** end-to-end: все CUDA matmul/dequant kernels, доступ и раскладка экспертов, grouped prefill, memory/cache, loader, host paths; сравнить с донором, защитить Q4/IQ3.
4. **Native Q8_0 и Huihui Q8_0**: pack, GGUF, shards, Q8 dense и expert kernels, memory, MTP/PLE n-gram, не ограничиваться Q8_0 PLE.
5. Аудит и адресная интеграция всех отсутствующих возможностей из `Strata-main(1).zip` — модельная матрица Swift/Q4_0/Q4_K_S/другие IQ/Q8, инструменты/код, не копировать весь донор.
6. Runtime параметры без фиктивных ползунков: threads, context overflow, KV dtype, resident/cache, MTP/speculation, adaptive spec depth, thinking budget, разные модели. Разделить per-request и restart-only.
7. Обнаружение и безопасное переключение модельных профилей в веб/API без одновременной загрузки огромных GGUF.

### P1

8. Истории больших чатов/файлов: IndexedDB и квота, редактирование/удаление вложений после отправки, конкуренция вкладок, восстановление повреждённой истории.
9. API, MCP, CORS, URL/CSRF, логи, секреты и безопасная публикация историй.
10. Улучшение переносимости Q4/Huihui/IQ3_S профилей между ПК, не изменяя проверенные приватные конфиги первой машины.
11. Единая система тестов кодовых функциональных веток и актуальная документация, матрица моделей, без заявлений об успехе GPU без реального испытания.
