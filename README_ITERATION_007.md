# Strata Custom v0.1.39 — итерация 007

Полный архив включает исходники 001–007, а не готовый Windows `strata.exe`.

**Основное изменение:** экспорт/импорт полной истории разговоров в JSON, без потери содержимого текстовых вложений и встроенных изображений. Добавлена резервная копия повреждённого browser-local хранилища. Кнопки расположены рядом со списком разговоров: Export all, Import all, Raw backup.

Формат: `strata-chat-history` версии 1, до 100 чатов, максимальный JSON-архив 32 МиБ. Приватные сведения, которые пользователь или модель написали в беседах, будут находиться в экспортируемом файле. Не публиковать такие файлы в GitHub.

Исходная точка для Git: `bb4b6ff`, ветка `strata-v0.1.39-custom`. Обновляемые файлы: `serve/web/chat_sessions.js`, `serve/web/test_chat_sessions.js`, `serve/web/app.js`, `serve/web/index.html`, `serve/test_server.py`, `README_RU_CUSTOM.md`, `README_ITERATION_007.md`, `CONTINUE_PROMPT.md`, а также `docs/reports/iteration-007/`.

**Все команды для распаковки, точечного переноса, проверки Git и публикации приводятся непосредственно в чате** — пользователь не должен искать их здесь. Не использовать `git add -A`: неотслеживаемый `tj` является посторонним файлом.

Статус: завершённая кодовая итерация 007, не весь проект. Полные ограничения и результаты автоматизированных проверок: `docs/reports/iteration-007/REPORT.md`, остаток задач: `docs/reports/iteration-007/TASKS.md`, продолжение в новом чате: корневой `CONTINUE_PROMPT.md`.
