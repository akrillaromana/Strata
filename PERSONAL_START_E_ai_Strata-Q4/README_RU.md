# Персональные профили E:\ai\Strata-Q4

**Форк предназначен только для личной конфигурации владельца. Не рекомендую запускать его как есть на чужих компьютерах.**

Все BAT/PS1 и JSON находятся здесь в одной плоской папке — точно так же, как должны располагаться в `E:\ai\Strata-Q4`, если владелец позже решит применить их к своей установленной Strata. **Сейчас ничего копировать на E: не требуется:** стадия разработки ограничена GitHub и исходниками.

Исходные пути сохранены намеренно: `E:\ai\Strata-Q4`, `E:\ai\Strata-data`, `E:\ai\models`, RAM-диск `R:`, `C:\Program Files\AIM Toolkit`. Конфигурации `strata-unsloth-q8_0.json` и `strata-unsloth-ud-q4_k_xl.json` не создают пакеты, RAM-диск или модель автоматически.

Используемые личные сценарии: `START-HERE.bat` (Q4_K_XL), `START-HERE-HUIHUI.bat` (Huihui Q4_K_XL) и `START-HERE IQ3_S.bat` (IQ3_S). Их PS1 и все зависимости находятся рядом. `START-QUALITY-RAM.cmd` жёстко привязан к E:, это осознанно.

Q8 JSON **требует оригинальный Q8_0 n-gram**: удалена ссылка на IQ4_NL PLE; движок с `--native` выбирает `per_layer_token_embd.weight` из шардов `R:\q8-model` и проверяет `--ple-require-type Q8_0` (160 × 320001536, 170 байт/строка). Без оригинальной Q8_0 таблицы запуск обязан завершиться ошибкой, а не использовать IQ4_NL. Ручная диагностика заголовка без CUDA: `python tools/q8_ple_preflight.py R:\q8-model\Qwen3.8-Flash-Next-Q8_0-00001-of-00006.gguf` из корня репозитория. Требуется **новый** скомпилированный движок с поддержкой флага; ранее установленный бинарник может не знать этот аргумент. Пока настоящий Q8 GGUF не предоставлен для проверки, запуск с моделью НЕ подтверждён.

Важно: сценарии управляют общей временной памятью `R:` и останавливают определённые локальные процессы; некоторые требуют повышения прав. Запускать только на собственной машине, после отдельного решения владельца о начале эксплуатационной фазы. `0.0.0.0:8080` открывает API в локальной сети; требуется защита сети и ключ доступа при необходимости.

После ручной правки `sampling`, `repeat_stop_tokens` или дополнительных настроек в корневых JSON-файлах PS1 больше не должен стирать эти параметры при пересоздании путей. Прежняя версия JSON сохраняется в `.bak`. У Huihui сохранены SHA-256 проверки PLE и индекса пакета. При повреждённом JSON сценарий останавливается без его перезаписи.

Источник истины для Git: `tools/windows/q4-local-profiles/` (те же 24 файла). Этот каталог и текущий являются побайтово одинаковыми наборами BAT/PS1/JSON; их соответствие проверяется автоматически.
