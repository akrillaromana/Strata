# Локальные сценарии Windows для Q4, Huihui и IQ3_S

Эти файлы сохранены как **исторический снимок рабочей установки**. Они не заменяют официальный `START-HERE.bat` в корне репозитория. В них имеются жёсткие пути `E:\ai\Strata-Q4`, `E:\ai\Strata-data`, `E:\ai\models`, `R:` и `C:\Program Files\AIM Toolkit`. Встречаются команды с повышенными правами для создания RAM-диска, ссылок, копирования и остановки процессов.

Перед повторным использованием на иной машине нужно вручную изучить каждую команду, проверить пути и добавить подтверждения к изменяющим/удаляющим операциям. Это *не* универсальный переносимый установщик. Профили относятся к конкретным моделям, а не к классам моделей; нельзя смешивать Unsloth и Huihui pack.

Самые актуальные локальные запускающие сценарии: `START-Q4-RAM.ps1`, `START-HUIHUI-Q4-RAM.ps1`, `START-IQ3S-RAM.ps1`, соответствующие `.bat`. Диагностические программы `PREPARE-HUIHUI-Q4.py` и `DIAGNOSE-HUIHUI-GGUF.py` лежат рядом со сценариями, как в оригинальной установке. `TEST-PREPARE.py` рассчитан на синтетические данные, не на настоящие веса.

Сохранены параметры Q4/Huihui: `--spec 4`, `--spec-min-p 0.5`, `--suffix-draft 0`, `--kv int8`, `--kv-resident 32768`, `--max-context 262144`, `--resident-budget-gib 80`, `--pcie-frac 0`, `--adapt-every 0`, `--adapt-swaps 0`, `--prompt-cache 0`, бюджет 10240, bind `0.0.0.0:8080`. Эти конкретные профили проверялись пользователем на исходной машине. Произвольную конфигурацию под другое железо ими подменять нельзя.
