# Персональные профили E:\ai\Strata-Q4-Fork

**Форк предназначен только для личной конфигурации владельца. Не рекомендую запускать его как есть на чужих компьютерах.**

Личные BAT/PS1 и JSON находятся в этой папке. После самостоятельной распаковки полного архива она остаётся под `E:\ai\Strata-Q4-Fork\PERSONAL_START_E_ai_Strata-Q4-Fork`; также доступны корневые точки входа Q4, Huihui и Q8.

Исходные пути сохранены намеренно: `E:\ai\Strata-Q4-Fork`, `E:\ai\Strata-data`, `E:\ai\models`, RAM-диск `R:`, `C:\Program Files\AIM Toolkit`. Конфигурации `strata-unsloth-q8_0.json` и `strata-unsloth-ud-q4_k_xl.json` не создают пакеты, RAM-диск или модель автоматически.

Используемые личные сценарии: `START-HERE.bat` (Q4_K_XL), `START-HERE-HUIHUI.bat` (Huihui Q4_K_XL), `START-HERE IQ3_S.bat` (IQ3_S) и `START-HERE Q8_0.bat` (исходный Unsloth Q8_0). В корне форка доступны `START-Q4-RAM.ps1`, `START-HUIHUI-Q4-RAM.ps1`, `START-Q8-RAM.ps1` и `START-IQ3S-RAM.ps1`. Обычный Q4 и Huihui больше не требуют локального `.venv`: сначала ищется он, затем Python 3.10+ из PATH; CUDA/MSVC DLL подготавливаются общим проверяющим модулем. Вывод запросов, префилла и скорости теперь отображается в терминале по умолчанию; `-Detached` включает прежний фоновый режим.

Q8 JSON **требует оригинальный Q8_0 n-gram**: ссылка на IQ4_NL PLE запрещена; движок с `--native` выбирает `per_layer_token_embd.weight` из шардов `R:\q8-model` и проверяет `--ple-require-type Q8_0` (160 × 320001536, 170 байт/строка). `START-Q8-RAM.ps1` предварительно проверяет все 6 шардов и исходный Q8_0 PLE через `tools/q8_ple_preflight.py`, до изменений на RAM-диске. Нужен **собственный** нативный пакет Q8 с `tokenizer`: ожидаются `E:\ai\Strata-data\packs\unsloth-q8_0` или `E:\ai\Strata-data\packs\q8_0`. Поскольку пути и исходники владельца здесь недоступны, можно явно указать `-ModelsDirectory` и `-PackSource`. Пакеты IQ3_S/Q4 подставлять нельзя. Нужен скомпилированный движок с поддержкой флага. Реальный запуск Q8 на RTX 3060 ещё не подтверждён.

Важно: сценарии управляют общей временной памятью `R:` и некоторые старые Q4-сценарии останавливают локальные процессы; запускать только на собственной машине с правами администратора. Новый Q8-запускатель ничего автоматически не завершает, сначала требует остановить работающий сервер, а также проверяет метку RAM-диска `STRATA_PLE`. `0.0.0.0:8080` открывает API в локальной сети; требуется защита сети и ключ доступа при необходимости.

После ручной правки `sampling`, `repeat_stop_tokens` или дополнительных настроек в корневых JSON-файлах PS1 больше не должен стирать эти параметры при пересоздании путей. Прежняя версия JSON сохраняется в `.bak`. У Huihui сохранены SHA-256 проверки PLE и индекса пакета. При повреждённом JSON сценарий останавливается без его перезаписи.

Источник истины для Git: `tools/windows/q4-local-profiles/` (те же 24 файла). Этот каталог и текущий являются побайтово одинаковыми наборами BAT/PS1/JSON; их соответствие проверяется автоматически.
