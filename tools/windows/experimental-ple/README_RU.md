# Экспериментальные утилиты PLE

Исследовательские сценарии изготовления отдельного GGUF с PLE из метаданных одного сегмента и тензора другого. На рабочей Q4/Huihui **не требуются**: штатный многосегментный загрузчик после исправления работает с оригинальными шардами.

Сценарии перезаписывают заданный пользователем выходной файл, если он существует. Не запускать на оригинальных GGUF; использовать только отдельные копии с достаточным свободным местом. Реальные большие файлы не входят в репозиторий.
