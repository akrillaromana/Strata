# Strata Custom v0.1.39 — итерация 016

Персональный форк владельца, **не рекомендуется использовать другим пользователям как есть**.
Изменена исходная реализация MTP runtime: строгая валидация `dense.txt`,
`dense.bin`, `experts.bin`, защита от чужого/повреждённого runtime-каталога,
проверка реального типа packed MTP GGUF перед конверсией.

Четыре Unsloth MTP GGUF (BF16/Q8_0/shared) **ещё не получили полноценный
нативный converter/runtime**. Не путать отказ от неправильной загрузки и
реальную поддержку. Восемь пользовательских вариантов модели в
`data/personal_models.json` сохраняются; личные пути и BAT/PS1/JSON не
изменялись. Работа только над исходниками, без запуска моделей/движка.

Подробности: `docs/reports/iteration-016/REPORT.md` и `TASKS.md`.
Для продолжения — корневой `CONTINUE_PROMPT.md`.
