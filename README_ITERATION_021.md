# Strata Custom — итерация 021

Сделан единый строгий путь чтения многосегментных GGUF для нативных матриц Unsloth Q6_K и Huihui/Unsloth Q8_0: сначала `GgufModel` подтверждает целостность **всей семьи** шардов, только затем CUDA-загрузчик имеет право копировать веса. При несоответствии `split.tensors.count`, повторе тензора, чужом shard metadata загрузка отклоняется. Исправлен также размер буфера числовой части split-имени для GCC `-Werror`. Улучшены C++/Python GGUF-ридеры и добавлены автономные отрицательные тесты.

Проверяется код, **не** работоспособность модели на GPU. Полное Q6_K/Q8_0 end-to-end, Vision/mmproj, structured token-level JSON Schema и другие задачи пока не завершены. Пользовательская работающая установка и профили не изменялись. Подробности `docs/reports/iteration-021/REPORT.md` и `CONTINUE_PROMPT.md`.
